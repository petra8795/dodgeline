# Dodgeline – website

Landing, support and privacy pages for the Dodgeline iPhone game, served by GitHub Pages.

- Landing: https://petra8795.github.io/dodgeline/
- Support: https://petra8795.github.io/dodgeline/support.html
- Privacy policy: https://petra8795.github.io/dodgeline/privacy.html

## At launch
In `index.html`, replace the "Coming soon on the App Store" button (`id="appstore"`) with Apple's official
"Download on the App Store" badge linking to your App Store URL. See the comment above the button.
